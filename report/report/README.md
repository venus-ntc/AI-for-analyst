# Vân – Retail Data Preparation

## Tài liệu trong thư mục này

1. `VAN_REPORT.md` – nội dung báo cáo phần công việc của Vân.
2. `SETUP.md` – hướng dẫn cài đặt và chạy project bằng VS Code + Python + PostgreSQL local.
3. `BUSINESS_GLOSSARY.md` – Business Glossary phục vụ Semantic Mapping/Text-to-SQL.
4. `TEXT_TO_SQL_TEST.md` – bộ câu hỏi kiểm thử Text-to-SQL.

## Cách dùng

Copy thư mục `report/` này vào thư mục project:

```text
retail-ai/
├── data/
├── scripts/
├── sql/
└── report/
    ├── VAN_REPORT.md
    ├── SETUP.md
    ├── BUSINESS_GLOSSARY.md
    └── TEXT_TO_SQL_TEST.md
```
